# ADR-0008: Apache-2.0 for code, CC-BY-4.0 for data

- Status: Accepted
- Date: 2026-11-22

## Context

Companies and other scanners should be able to adopt both the tool and the data easily.

## Decision

License code under Apache-2.0 and the dataset under CC-BY-4.0, matching the PyPA Advisory Database.

## Alternatives considered

AGPL; a custom data license.

## Consequences

- Low adoption friction.
- Attribution is required when the data is reused.
